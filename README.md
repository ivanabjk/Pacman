# Pac-Man

Pac-Man is a maze game where you guide a yellow character through corridors filled with dots. The goal is to eat all the dots while avoiding ghosts that chase you around.

## How to Play
- Use the arrow keys (or WASD) to move Pac-Man.
- Eat all the small dots to clear the level.
- Power pellets (the big flashing dots) let you turn the tables — ghosts turn blue and can be eaten for bonus points.
- Watch out: if a ghost touches you while it’s not blue, you lose a life.
- The game ends when you run out of lives.
